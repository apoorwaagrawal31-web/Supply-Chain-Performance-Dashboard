# Supply Chain Performance Dashboard

## Project Overview
This project uses Power BI to analyze supply chain operations, costs, inventory, product quality, and transportation performance.

## Key Metrics
- Total SKUs
- Total Costs
- Average Defect Rate
- Total Order Quantity

## Dashboard Analysis
- Average defect rate by product type
- Order quantity by transportation mode
- Total and average cost by location
- Inspection results: Pass, Fail, and Pending
- Cost analysis by location and route

## Tools Used
- Power BI
- Microsoft Excel
- DAX for measures and calculations

## Dataset
The dataset contains 100 SKU records with information on product types, suppliers, locations, transportation modes, routes, costs, order quantities, and inspection results.

## Objective
To identify cost patterns, monitor product quality, compare transportation modes, and support data-driven supply chain decisions.
